# title-case-file-name

Require TitleCase file names for JavaScript and Vue files, with optional .test suffix.

## Rule details

❌ Examples of **incorrect** code:
```js
const lowerCamelCaseName = true;
const lowerCaseDotTest = true;
```

✔️ Examples of **correct** code:
```js
const fooBar = true;
const fooBarDotTest = true;
```

❌ Examples of **incorrect** code:
```vue
const lowerCamelCaseVue = true;
```

✔️ Examples of **correct** code:
```vue
const fooBarVue = true;
```
